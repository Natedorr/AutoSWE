## The issue

**Title**

```
[E2E-04] Add an MIT license header to src/toolbox.py
```

**Body**

```
Add a short MIT license header comment at the top of `src/toolbox.py`. Nothing else.
```

## The process

| # | openclaw posts | wait for | then check |
|---|---|---|---|
| 1 | `/fix` | `autoswe:fixed` | no `autoswe:planning` or `autoswe:planned` label was ever seen; the header is on the task branch |

## Status path

```
(new) → pending → fixing → fixed
```

## Must never appear

`planning` · `planned` · `waiting` · `failed` · `error`

## Why this case exists

A plan is optional. `/fix` on an issue that has never been planned must go straight to the fix
phase — not silently plan first, and not refuse for want of a plan. The must-never list is the
whole assertion.
