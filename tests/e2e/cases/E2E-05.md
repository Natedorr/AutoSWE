## The issue

**Title**

```
[E2E-05] Ensure README.md ends with a newline
```

**Body**

```
Make sure `README.md` ends with a trailing newline. If it already does, change nothing and
say so.
```

`README.md` already ends with a newline — see [`../SETUP.md`](../SETUP.md).

## The process

| # | openclaw posts | wait for | then check |
|---|---|---|---|
| 1 | `/fix` | `autoswe:fixed` | the completion comment says no changes were needed; branch `autoswe/issue-<N>` has **no new commit** — an empty branch, or no branch at all |

## Status path

```
(new) → pending → fixing → fixed
```

## Must never appear

`failed` · `error` · `test_failed`

## Why this case exists

"Nothing to do" is a success, not a failure — the fix phase reporting no changes still rests
at `fixed`. What must not happen is an empty or invented commit to make the run look
productive.

The label is the cheap half of this case. The assertion that matters is the absence of a
commit.
