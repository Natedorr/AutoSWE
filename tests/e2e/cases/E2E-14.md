## The process

| # | openclaw posts | wait for | then check |
|---|---|---|---|
| 1 | `/plan` | `autoswe:planned` | a plan was posted |
| 2 | `/abort` | `autoswe:aborted` | a comment says the task was aborted |
| 3 | `/fix` | `autoswe:fixed` | the task restarted from `aborted` and produced the change |

## Status path

```
pending → planning → planned → pending → aborted → pending → fixing → fixed
```

## Must never appear

`failed` · `error`

## Why this case exists

`aborted` must be a **parking** state, not a terminal one. Abandoning a task and later picking
it up again is ordinary usage, and step 3 proves the restart path is open.

The restart also carries its attempt count forward rather than resetting it — an abort is not
a fresh start, only a resumable stop.
