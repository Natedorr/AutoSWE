# E2E-13 — `/skip`, and plain text that means nothing

| | |
|---|---|
| **Group** | steering |

## The issue

**Title**

```
[E2E-13] Something we will not do
```

**Body**

```
This issue exists to be skipped. Do not implement anything.
```

## The process

| # | openclaw posts | wait for | then check |
|---|---|---|---|
| 1 | `/skip` | `autoswe:skipped` | no agent ran, no `autoswe/issue-<N>` branch was created, no commit anywhere |
| 2 | `just checking in` — plain text | **no label change** across two wake-ups | plain text on a task that is not waiting for a reply does nothing at all |

## Status path

```
(new) → pending → skipped
```

## Must never appear

`planning` · `fixing` · `failed` · `error`

## Why this case exists

`/skip` must be free: it parks a task without spending a model call or touching git. Step 2 is
the quieter assertion — chatter on an issue must not wake a parked task. A task only re-opens
on a slash command, or on a reply to a question it actually asked.
